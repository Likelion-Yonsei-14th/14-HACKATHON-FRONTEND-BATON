미정 — 확인 필요 12건

값을 임의로 만들지 않았습니다
1. 한글 폰트Outfit에 한글 없음. 기존 SUIT 유지 / Pretendard / 다른 것?
2. 바통 상태 9종 색시스템 시그널은 flame·red·lime·amber(예약)·sky(예약)뿐. DRAFT/ARMED/WAITING/PENDING_REVIEW/EXECUTED/COMPLETED/EXPIRED/CANCELLED/ERROR 9종 매핑 필요.
3. Badge 컴포넌트시스템엔 SourceTag/DeltaBadge만 있음. 상태 배지를 SourceTag 스타일로 파생할지 결정 필요.
4. 텍스트 입력 / textareaSearchInput(알약형 44px)만 정의됨. 라벨 있는 폼 필드·여러 줄 textarea 스펙 없음.
5. Dialog / 모달컴포넌트 없음. 스크림 rgba(11,11,11,.28)+blur 3px은 가이드 문장에만 있고 토큰 파일엔 없음.
6. StepTabs (3단계 위저드)스테퍼/탭 컴포넌트 없음. FilterChip 파생 또는 ScheduleBar(라임=현재 단계) 파생 중 선택.
7. 라디오 · 토글 · 셀렉트보류 처리 화면의 분기 라디오, 설정 화면의 셀렉트/토글 스펙 없음(SelectPill만 존재).
8. 헤더 + 텍스트 사이드바시스템은 “페이지 크롬 없음 + 라벨 없는 56px 아이콘 레일”. 기존 AppShell(헤더+텍스트 메뉴)과 1:1 아님 → 2단계에서 결정.
9. 인라인 알림 / 에러 면연결 실패·동기화 실패 안내면. red-100·flame-100은 있으나 시맨틱 정의 없음.
10. AA 대비 예외--text-faint(#9a9a9a)는 흰 배경 2.6:1로 AA 미달. 본문/라벨 금지·장식 전용으로 제한할지 확인.
11. 기술 스택브리핑의 스택 항목이 예시 그대로 비어 있음. Tailwind 유무에 따라 3단계 산출물 형식이 달라집니다.
12. 반응형 · 다크모드시스템에 브레이크포인트도 다크 테마도 정의 없음(캔버스는 항상 밝은 회색). 모바일 지원 범위 확인 필요.

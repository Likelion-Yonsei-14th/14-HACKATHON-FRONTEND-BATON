C. 바통 상태 9종 → 시그널 3색

라임은 “완료” 하나에만, 화면 전체에 라임 면(카드 배경)은 쓰지 않고 도트·배지 크기의 마크로만 사용합니다 (시스템 배급 규칙 준수).
EXECUTED · COMPLETED — 발송 완료 PENDING_REVIEW — 검토 필요 ERROR — 오류 발생 WAITING · ARMED — 답장 기다리는 중 DRAFT — 작성 중 EXPIRED — 만료됨 CANCELLED — 취소됨
WAITING(ink-800)과 EXPIRED/DRAFT(ink-400)는 도트 명도로 구분하고, 배지 텍스트가 상태명을 그대로 말합니다 — 색만으로 정보를 전달하지 않음(AA 1.4.1).

F. 승인 후 진행 순서

3토큰 정의 파일 — src/index.css(CSS 변수 + 폰트) + tailwind.config.js(var() 참조 테마). 새 의존성 없음.
4랜딩 → 헤더/사이드바(AppShell) → 공통 컴포넌트(Button·Panel·Badge·Dialog·StepTabs·Field) → 홈 → 위저드 3화면 → 상세/보류/결과 → 인증·연결·에러 → 설정. 화면 단위로 끊어서.
